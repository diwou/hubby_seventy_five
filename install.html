HUB75 NTP Flip Clock

Firmware direkt im Browser per USB auf einen ESP32-S3 flashen. Fuer bereits laufende Geraete bleiben Updates wie gehabt bequem ueber das Webinterface moeglich.

Empfohlen: Chrome oder Edge mit USB-Datenkabel

Falls der Button keinen Port findet: anderes USB-Kabel probieren und sicherstellen, dass es ein Datenkabel ist, nicht nur ein Ladekabel.

So geht's

  1. ESP32-S3 per USB anschliessen.
  2. Auf Connect klicken und den seriellen Port auswaehlen.
  3. Bei einem neuen Geraet die vorgeschlagene Loeschung bestaetigen.
  4. Warten, bis das Flashen abgeschlossen ist.
  5. Danach das Geraet neu starten oder kurz neu einstecken.

Hinweise

Diese Seite verwendet ESP Web Tools und das automatisch erzeugte Manifest unter Firmware/latest/manifest.json. Damit wird immer der zuletzt gebaute Firmware-Stand verwendet.

Wenn das Geraet bereits laeuft, ist ein OTA-Update ueber das Webinterface meist einfacher als ein erneutes USB-Flashen.
